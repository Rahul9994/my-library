=== 2026-06-27_Most-Data-Scientists-structure-their-projects-the-wrong_DaFhqfuBkpb  [1 slides]
https://www.instagram.com/p/DaFhqfuBkpb/
Most Data Scientists structure their projects the wrong way.

Use this clean, production-ready layout 👇

1️⃣ config/ – Configuration files
Separate parameters from code.
Example: local.yaml, prod.yaml

2️⃣ data/ – Full data lifecycle
raw → preprocessed → features → predictions

3️⃣ entrypoint/ – Main scripts
train.py for training pipelines
inference.py for batch or real-time inference

4️⃣ notebooks/ – Exploration only
Use notebooks for EDA and analysis — never for production logic.

5️⃣ src/ – Core ML code
Feature engineering, training, and inference logic — modular and testable.

6️⃣ tests/ – Automated checks
Prevent silent failures before they reach production.

7️⃣ Docker + environment files – Reproducibility
Keep the same setup across machines and CI/CD.

8️⃣ Pinned dependencies – Stability
Exact package versions = consistent results

Chunking can make or break your RAG system 🚀

If retrieval feels off, the problem is often how you split the data — not the model.
From fixed-size to semantic, hierarchical, and metadata-aware chunking, each strategy impacts context retention, recall, and answer quality.

👉 Pick the chunking method based on document type + query pattern, not randomly.
Smart chunking = better retrieval = smarter GenAI.

=== 2025-12-01_RAG-was-supposed-to-make-LLMs-smarter_DRvvwgcgbvb  [1 slides]
https://www.instagram.com/p/DRvvwgcgbvb/
RAG was supposed to make LLMs smarter.
Ground them in facts. Give them memory.

But the truth?

Most RAG systems today are just fancy search engines—fetching chunks and hoping the model figures it out.

That’s not intelligence.

The real upgrade is Agentic RAG.

Tools like Glean, Perplexity, and Harvey don’t just retrieve… they reason.
They decide what to fetch, when to fetch, or whether they should fetch anything at all.

This changes everything:

• No blind embeddings
• No random chunk dumps
• Real, layered memory
• APIs, search, and tools inside the reasoning loop

The LLM stops guessing and starts thinking.
