UPPER() / LOWER() → Uniform casing
TRIM() → Remove extra spaces
REPLACE() / REGEXP_REPLACE() → Clean unwanted characters

📅 4. Fix Dates
TO_DATE(string, format) → Standardize formats
EXTRACT(YEAR | MONTH | DAY) → Break down components

📊 5. Handle Outliers
Use AVG() + STDDEV() → Detect unusual values
Cap or filter values beyond the threshold

🔍 6. Detect Entry Errors
REGEXP → Spot invalid emails or phone numbers

🏷️ 7. Standardize Categories
CASE WHEN or mapping tables → Normalize inconsistent entries

💬 8. Remove Special Characters
REGEXP_REPLACE() / REPLACE() → Clean text columns
