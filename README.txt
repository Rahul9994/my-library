THE LIBRARY
===========

Open   : double-click  index.html   (works offline, no server needed)

Keys   : <- ->  or drag / wheel   move along the shelf
         Enter / click the lifted cover   open a book
         /  or  Ctrl+K            search
         Esc                      go back

Folders
  tajamul.codes_cheatsheets/           104 cheat sheets   (the slides, one folder per book)
  tajamul.codes_code_posts/             91 SQL / Python code + notes
  tajamul.codes_projects_RAG_PowerBI/   20 projects, RAG and Power BI
  _site/                                the website itself (css, js, fonts, thumbnails)

Adding more books later
  1. Put a new book folder (01.jpg, 02.jpg ...) into one of the three collection folders.
  2. Run:   python _site\tools\build_library.py
     It rebuilds the aligned thumbnails (4:5, nothing cropped off) and the catalogue.

All sheets are by Tajamul Khan (@tajamul.codes) - kept here as a personal reading library.
